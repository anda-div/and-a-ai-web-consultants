# defaults — 汎用の既定値

レポート生成の既定値です。**クライアント固有の値は含みません。**

利用者側の `_config/` に同じキーがあれば、そちらが優先されます（上書き方式）。

| ファイル | 何の既定か |
|---|---|
| `report_defaults.json` | 章立て、出力先とファイル名、競合比較の方法論、ページ型の座標 |
| `branding_defaults.json` | 本文の最小サイズ、既定配色、箱の余白ルール、ヒートマップ座標 |
| `data_source_defaults.json` | 入力フォルダ構成、GASが出力するシート名 |
| `angles_catalog.json` | 分析の切り口カタログ（問い・必要なデータ・出やすい所見） |
| `ledger_rules.json` | 費用帯、効く指標の決め方、状態の定義、保留の扱い |
| `proposals_inbox.json` | 過去資料の取り込み口の仕様（箱と状態の対応、必須項目、前段チェック） |
| `inbox_readme_template.md` | 取り込み口に置く、クライアントへの1枚説明のひな形 |

`inbox_readme_template.md` は `ledger.py --init-inbox` が案件側へ複製します。
**そのまま渡せる文面**にしてあるので、直すときは相手が読むことを前提に直してください。

## なぜ既定値を公開側に置くのか

`_config/` は納品後、クライアントのPC上に置かれます。提供者が直接は直せません。

既定値を公開リポジトリ側に置いておけば、より良いやり方を見つけたときに
**「最新版をダウンロードしてください」の一斉連絡だけで全利用者へ届きます。**
`_config/` を個別に直してもらう必要がありません。

したがって **`_config/` には「その案件でしか決められないこと」だけ**を残してください。

| Config に置く | 既定値に置く |
|---|---|
| 会社名、計測ID、URL、対象期間 | 章立て、ページ型の座標、体裁ルール |
| テンプレートのパスと実測座標 | 競合比較の方法論、シート名 |
| 競合の具体名、固有名詞リスト | 出力ファイル名の形式 |

## 上書きの粒度

キー単位で上書きされます。`geometry_cm` の一部だけを変えたい場合は、
変えたいキーだけを `_config` 側に書けば足ります。全部を書き写す必要はありません。
