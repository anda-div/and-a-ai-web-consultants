# これまでの施策の資料を、このフォルダへ入れてください

毎月の改善提案から、**すでに実施したもの・いま進めているもの・一度見送ったもの**を
外すために使わせていただきます。

同じ提案をもう一度お出ししないための準備です。

---

## お願いしたいこと

**箱を選んで、ファイルを置くだけ**で終わりです。名前を変える必要も、書き直す必要もありません。

| フォルダ | 入れるもの |
|---|---|
| `00_未分類` | **迷ったらここで構いません。**こちらで分類の下書きをします |
| `10_過去の定期レポート` | 過去に受け取った提案書・レポート（他社のものも含みます） |
| `20_実装済み` | すでに実施したもの |
| `30_却下・結論が出ていない` | 見送ったもの、結論が出ていないもの |
| `40_実装中` | いま作業が進んでいるもの |
| `50_実装予定` | 実施が決まっているが、まだ着手していないもの |

### 形式は問いません

Word、Excel、PowerPoint、PDF、テキスト、どれでも構いません。
提案資料そのものでなくても、**議事録の一部やメールの抜粋**で十分です。

資料が残っていない場合は、**箇条書きのメモ**で構いません。

```text
・トップページの問い合わせボタンを右上に移動   2025年の秋ごろ実施
・料金表のページを作る   見積を取ったが、そのままになっている
・チャット窓の設置   社内で反対があり見送り
```

この程度で役に立ちます。

### 実施した時期が分かると、とても助かります

**「8月の後半」「去年の秋」でも構いません。**

おおよその時期が分かれば、その前後で数値を比べられます。
日付が無いと、数値が動いた理由をその施策に結びつけられません。

---

## こちらで行うこと

1. 置いていただいた資料を読み、提案の一覧（台帳）に1回だけ書き写します
2. 原本は `_archive` へ移します。**以後は読み直しません**
3. こちらの理解を記入した**確認シート**をお出しします

確認シートは、**違っているところだけ訂正していただく**形です。
すべてにご回答いただく必要はありません。空欄を埋めるより、書かれた内容を直すほうが早いためです。

---

## ファイルは動かさないでください

一度置いていただいたファイルは、**そのままにしておいてください。**

状態が「実装予定 → 実装中 → 実装済み」と変わっても、
フォルダを移し替える必要はありません。**状態はこちらが台帳の側で更新します。**

ファイルを動かす運用にすると、数か月で誰も動かさなくなります。
**このフォルダは入口で、最新の状態は台帳のほうにある**、という分け方にしています。

---

## 見送った提案について

**「見送った」は「二度と出さない」ではありません。**

- 予算の都合で見送ったものは、次の期に出し直せます
- 「次のリニューアルのときに」は、見送りではなく**時期待ち**として記録します

そのため、見送られたものについては
**「何を待っているか」と「いつ頃また見るか」**だけ、ひとことお聞かせください。

理由が分かると、同じ提案を的外れな時期にお出しせずに済みます。

## よくあるご質問

**Q. 全部埋めないといけませんか**
いいえ。**空のままの箱があって構いません。**
こちらで持っている資料からは、こちらで先に書き写します。
お願いしたいのは、**こちらが持っていない資料**（他社が作った提案書、社内のメモ）だけです。

**Q. 古い資料でも意味がありますか**
あります。**実施済みかどうかが分かること自体が目的**なので、古さは問題になりません。

**Q. 個人情報や社外秘が含まれています**
その部分を削ってからお渡しください。提案の内容と時期が分かれば十分です。
