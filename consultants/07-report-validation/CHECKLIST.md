# 納品前チェックリスト

## 1. 数値と定義

- [ ] `scripts/check_values.py` を通し、「要対応」が0件である
      （そろって0 / 期間の逆転 / 期間のずれ / 前月から0へ）
- [ ] `check_values.py` の「確認」を、該当ページを開いて1件ずつ見た
- [ ] 元データと掲載値を突合した
- [ ] 合計・差分・増減率を再計算した
- [ ] 期間、対象、除外条件、指標定義を明記した
- [ ] 0除算、欠損、丸め、率とポイント差を区別した
- [ ] 「事実」「仮説」「提案」「未検証」を区別した

## 2. 根拠と追跡性

- [ ] すべての重要主張に所見IDまたは出典がある
- [ ] 課題IDから所見ID、施策IDから課題IDを追跡できる
- [ ] 画像にURL・日付・デバイス・範囲の説明がある
- [ ] 反証候補と追加確認項目を残した

## 3. 施策品質

- [ ] 問題／施策／期待変化／根拠が揃っている
- [ ] PC/SP、通常・読込中・エラー・該当なしを確認した
- [ ] 実装制約、計測イベント、受入条件がある
- [ ] 次回検証する主要指標とガードレール指標がある

## 4. 表示・文章

- [ ] スライドまたは文書を最終形式でレンダリングした
- [ ] 文字切れ、重なり、極端に小さい文字、低解像度画像がない
- [ ] 表・グラフの単位、凡例、軸、注記が読める
- [ ] 見出し、番号、固有名詞、表記、改行が一貫している
- [ ] 長文を減らし、結論と次の行動が一目で分かる

## 5. 公開・納品安全

- [ ] 仮名、内部メモ、変更履歴、コメント、非表示要素を確認した
- [ ] 認証情報、個人情報、他案件名、ローカルパスがない
- [ ] URL、ファイル名、対象企業、対象期間が正しい
- [ ] AI生成物を独立に再確認し、担当者が承認した
