# テンプレートの確認と適用

レポートの体裁は、あとから変えると手戻りが非常に大きくなります。
**生成を始める前に**、テンプレートの有無と用紙比率を確定させてください。

---

## 判断のながれ

```text
テンプレートは提供されているか？
├─ YES → 解析して100%準拠で生成する（§1）
└─ NO  → 「本当に無いか」を確認する（§2）
          ├─ 実は在った → §1へ
          └─ 本当に無い → 用紙比率を確認して既定テンプレートで生成（§3）
```

---

## 1. テンプレートが提供されている場合

**そのテンプレートに100%準拠して生成します。** 独自のテーマや配色で代替しません。

### 解析すること

生成を始める前に、テンプレートから次を読み取り、設定ファイルへ書き写します。

| 項目 | 読み取り方 | 書き込み先 |
|---|---|---|
| 用紙サイズ | `prs.slide_width / slide_height` | `branding.json` の `slide_size_cm` |
| レイアウト名 | `prs.slide_masters[0].slide_layouts` の各 `.name` | `branding.json` の `layouts` |
| 配色 | 既存スライドの図形・文字色を抽出 | `branding.json` の `colors` |
| フォント | 日本語／英数それぞれの既定 | `branding.json` の `fonts` |
| 本文領域の座標 | 既存スライドの本文・要約・注記の位置を実測 | `branding.json` の `geometry_cm` |
| 装飾 | ロゴ・フッター・罫線の有無と位置 | 生成時にレイアウトごと使う |

`scripts/inspect_template.py` が、この読み取りを補助します。

```bash
python scripts/inspect_template.py path/to/template.pptx
```

### 守ること

- **原本は編集しない。** 生成物は必ず別ファイルへ出力する。
- マスター／レイアウト／テーマを**そのまま使う**。独自テーマで作り直さない。
- ロゴ・フッターの線画・罫線などの装飾要素も再現する。
- レイアウト名はテンプレートごとに異なる。差し替えたら必ず見直す。

## 2. 提供されていない場合の確認

**ここを省くと、あとで大量の手戻りになります。**
「無い」と言われても、一度は次の形で確認してください。

> レポートのPowerPointテンプレートについて確認させてください。
>
> 御社に、既定のPowerPointテンプレート（提案書や報告書で使っている雛形）はございませんか。
> 次のいずれかがあれば、それをお使いいただけます。
>
> - 会社の標準テンプレート（.pptx / .potx）
> - 過去に他社へ提出した報告書のPowerPoint
> - ロゴ・配色・フォントの規定（ブランドガイドライン）
>
> **後からテンプレートを変更すると、全ページの作り直しになります。**
> いま一度ご確認いただけますでしょうか。

ブランドガイドラインだけがある場合は、それを元に既定テンプレートへ配色とロゴを反映してから進めます。

## 3. 本当に無い場合：用紙比率の確認

既定テンプレートを **16:9 と 4:3 の2種類**用意しています。
**どちらで作るかを、生成前に必ず確定させてください。**

| 比率 | サイズ | 向いている場面 |
|---|---|---|
| 16:9 | 33.87 × 19.05 cm | 画面共有・オンライン会議・プロジェクタ |
| 4:3 | 25.40 × 19.05 cm | 紙で配布・印刷して読む・情報量が多い表 |

確認の文面:

> テンプレートのご用意が無いとのことですので、当方の既定テンプレートで作成します。
> 用紙の比率をお選びください。
>
> - **16:9（横長）** … 画面で見る前提。オンライン会議での共有に向きます
> - **4:3（従来比）** … 印刷して配る前提。1ページに載る情報量が多くなります
>
> **後から変更すると全ページの再配置が必要になります。**
> 16:9でよろしいでしょうか。

決まったら `branding.json` の `template.path` を、対応する既定テンプレートに向けます。

```json
"template": { "path": "consultants/07-report-validation/templates/default_16x9.pptx" }
```

既定テンプレートは装飾を持たない素の雛形です。
配色だけでも先方の指定があれば `branding.json` の `colors` に反映してください。

## 縦に長いヒートマップの置き方

ヒートマップは「全ページを見せる」ためではなく「所見の根拠を示す」ために載せる。
全体を分割して横に並べる方式（`heatmap_slide`）は、ページが縦に長いほど1枚が細くなる。
実測では8列に分けたために幅が2.1cmに制限され、そこで縮尺が決まっていた。
縦の枠を13.5cm用意していても、画像は1.2cmまで縮み、スライドの下半分が空いた。

所見が触れる区間だけを拡大する `heatmap_focus_slide` を使う。

- **始点は作り手が決め、どこまで見せるかは枠が決める。**
  指定した区間が枠より縦に長ければ、始点を保ったまま縮める。
  読めない大きさの画像を載せても根拠にならないため。縮めた場合はビルド時に知らせる。
- 全体のどこを見ているかは、画像の左の縦棒で示す。
  全体像の縮小版を置く手もあるが、縦横比が30:1にもなるページでは幅が数ミリになり、
  何も読めない絵になる。
- 元画像の左右の白帯は自動で落とす。Clarityは表示領域の中央にページを縮小表示するため、
  実測では幅の6割が余白だった。

ScrollとClickで表示範囲がずれる場合、2枚の全体の高さが違う。
同じ手順で撮り直せば揃う。
