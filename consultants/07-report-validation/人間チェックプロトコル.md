# 人間チェックプロトコル

AIが生成したレポートを、同じ会話の流れだけで「問題なし」と判断しないための手順です。

1. 元データ、生成物、依頼条件を別々に保管する。
2. 数値検算、根拠追跡、表示確認を別工程として実行する。
3. 重大な主張を3件以上、元データまで逆向きにたどる。
4. 反対の説明が成立しないか、計測変更や外部要因を確認する。
5. 最終形式をPC/SPまたはスライド画像として目視する。
6. 修正後は変更箇所だけでなく全体を再確認する。
7. 納品判断者が、未検証事項と残余リスクを明示して承認する。

AIは速度と網羅性を高めますが、同じ誤前提を高速に展開することもあります。検算は生成工程から独立させてください。
